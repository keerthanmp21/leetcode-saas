# Dashboard UI Phase 2 Spec

## Overview

This is phase 2 of 3 for the dashboard UI layout. Use the screenshot referenced below for how it should look.

## Requirements for phase 2

- Collapsible sidebar
- Dashboard, Analytics, Settings
- Dashboard as default(since pointing to /dashboard)
- User avatar area at the bottom
- Drawer icon to open/close sidebar
- Always a drawer on mobile view
- At top Dashboard(Track your leetcode progress) icon and sync now button
- complement sidebar and header portions
